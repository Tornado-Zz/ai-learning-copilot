# 第一次使用：从零到第一个作品

> 本文按**空数据库**（全新克隆）的实际运行结果编写，每一步都是我在浏览器里点过的。
> 全流程不需要任何 AI Key；配置 Key 只会让「AI 导师」多出一条能力。

## 0. 先决条件

| 需要 | 版本 | 用途 |
| --- | --- | --- |
| Docker Desktop | 任意近期版本 | 跑 PostgreSQL 17，数据只在本机 `127.0.0.1:5432` |
| uv | 0.13+ | Python 依赖与命令入口 |
| Node.js | 22+ | 前端构建 |

## 1. 两条命令把系统跑起来

```powershell
git clone <仓库地址> && cd ai-learning-copilot
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-dev.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\smoke.ps1
```

- 第一条会：起 PostgreSQL → 等 healthy → 应用迁移 → 起 API（`127.0.0.1:8000`）→ 首次自动 `npm ci` 并构建前端 → 起 Web（`127.0.0.1:3000`）。
- 第二条是只读自检，17 项全 `PASS` 才算跑通。
- 首次运行大约 3–6 分钟（主要在装前端依赖和构建），之后每次启动几秒。

打开 <http://127.0.0.1:3000>。

## 2. 第一次打开会看到什么

**首页会明确告诉你「需要先确认时区」，并给一个「去档案页确认时区」的按钮。**
这不是 bug：`/plan` 与 `/` 在时区未确认前会返回 409，因为「今天 / 本周」必须绑定一个时区才算得准。
数据库里的种子用户 `timezone_source` 是 `default`，只有你显式确认后才会变成 `user_confirmed`。

## 3. 建档（约 1 分钟）

1. 点「去档案页确认时区」→ 进入 `/onboarding`。
2. 勾选每周的学习日（默认周一/周三/周五），填每天可投入分钟数（15–480，默认 60）。
3. **勾选「我确认我的时区是 …」**——不勾会提示「请勾选确认时区后再保存」，这是刻意的：时区错了，之后所有「今天 / 本周」都会错。
4. 点「保存并进入诊断」。

## 4. 能力诊断（20 题，约 10–15 分钟）

- 20 道题覆盖 6 个能力域，题型有单选、代码阅读、改错。
- 每答一题自动存草稿，刷新或关掉页面回来还在。
- 答完点「提交诊断」→ 进入 `/result`。

**怎么读结果**：每个域给出「等级 + 评估状态 + 本次正确率」。
正确率低于 60% 的域会显示 **「L0 · 已测未达标」**——意思是「这次没考到门槛」，**不是**你能力为零，也**不会**把你此前已建立的等级降下来。
诊断**永远不会**授予 L3 / L4。

## 5. 出第一份周计划（约 1 分钟）

进 `/plan`，如果还没有计划就点「重新生成本周计划」。它会：

- 只在你勾选的学习日排任务；
- 每天总分钟不超过你设的额度；
- 课程优先，其次**到期的错题复习**，最后才是新练习；
- 重复点击不会产生重复任务，也不会改写已经「完成 / 跳过」的行。

首页 `/` 会把今天的任务拎出来，并给一个「继续学习」入口。

## 6. 学一节课 → 做一道题（约 20–30 分钟）

1. `/learn` 选一节课 → 读正文 → 点「开始学习」，读完后点「标记完成」。
   - 打开课程**不会**自动算完成；进度只在你点按钮时写入。
   - 标记完成后，本周对应的计划项会在同一个事务里变成 `done`。
2. `/practice` 选一道题 → 在编辑器里写代码 → 点「提交判定」。
   - **不勾「我已在本地运行并通过」**：走静态规则判题，徽章是「已验证（静态规则）」。
   - **勾上**：走自检，徽章是「未验证（自检）」。
   - 系统**不会执行你的代码**；静态规则通过也不等于代码真的能跑。
3. 答错的题会自动进入错题本，第二天起在 `/review` 出现；答对后按 1 / 3 / 7 / 14 天推进，连续 3 次通过后标记完成。

## 7. 可选：让 AI 导师帮你看题

在课程或练习详情页展开「AI 导师」提问。它需要你在 `apps/api/.env` 里填 `DEEPSEEK_API_KEY`：

```ini
DEEPSEEK_API_KEY=sk-...        # 留空则 AI 端点返回 503，其它功能不受影响
```

回答会标注提示依赖等级；如果知识库里有相关内容，会附上**来源与抓取时间**。

## 8. 交第一个作品

`/projects` 会先给你四条达标要求（完成课程数、通过练习数、L2 域数、完成计划任务数），全部达标才能说明你具备做结业作品的条件。
不达标也能先提交作品——达标情况由提交时的快照记录。

提交后进入「自评」：选「通过 / 需要改进」、写备注、**勾选「我确认这是本人自评」**才能提交。
单用户本地版本**没有第三方评审者**，`reviewer` 列在数据库层只允许 `self`。

## 9. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| `start-dev.ps1` 报 Docker 未运行 | 先启动 Docker Desktop，等托盘图标就绪再运行 |
| `/plan` 返回 409 | 还没确认时区，去 `/onboarding` 勾选确认框并保存 |
| `smoke.ps1` 报「alembic at head」失败 | 若脚本先打印了 `NOTE shell DATABASE_URL is set`，说明 shell 里残留了 `DATABASE_URL` 覆盖了 `.env`，`unset DATABASE_URL` 后重试 |
| 端口 3000 / 8000 被占用 | 先关掉残留进程；`netstat -ano \| findstr :8000` 找到 PID 后结束 |
| 页面显示「接口不存在」 | 后端没起或起了旧版本，重启 API |

## 10. v0.1.x 还没有的东西

登录鉴权与多用户、真实的代码执行沙箱、第三方人工评审、自动停留计时、逐题解析文本。
